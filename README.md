# website-templates-hub

Modern Next.js monorepo for reusable industry website templates.

## Project structure

- `apps/business-corporate-template`
- `apps/restaurant-food-template`
- `apps/real-estate-template`
- `apps/e-ecommerce-template`
- `apps/portfolio-template`
- `apps/healthcare-pharmacy-template`
- `apps/education-school-template`
- `apps/transport-logistics-template`
- `apps/hotel-booking-template`
- `apps/NGO-organisation-template`
- `apps/demo-hub`
- `shared/components`
- `shared/config`
- `shared/styles`

## Quick start

```bash
npm install
npm run dev:hub
npm run dev:business
```

Each app is deployable independently on Vercel.
